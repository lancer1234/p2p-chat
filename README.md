# P2P Chat

一個簡單、即時的瀏覽器 P2P 聊天工具。

🌐 **立即使用：** https://lancer1234.github.io/p2p-chat/

## 怎麼使用

1. 開啟網站並設定至少 8 位 PIN。
2. 點「＋ 新增對話」。
3. 其中一人選擇「產生邀請 QR Code」。
4. 另一人選擇「掃描對方 QR Code」。
5. 掃描完成後即可開始聊天。

配對過的聯絡人會保留在聊天室列表中。之後可以直接從列表切換不同的一對一對話，不需要每次重新掃描 QR Code。

## 聊天室列表

P2P Chat 支援多個一對一聊天室。

- 每個聊天室會保存自己的聊天紀錄。
- 點選聊天室即可重新連線。
- 同一時間只會啟用目前開啟的聊天室連線。
- 按「返回」只會回到聊天室列表，不會刪除聊天紀錄。
- 若要刪除聊天室，可從聊天室列表移除。

## 連線方式

P2P Chat 會優先使用 **Direct P2P**，讓兩台裝置直接建立連線。

如果目前的 Wi‑Fi、行動網路或防火牆無法建立直接連線，畫面會提供 **使用加密 Relay** 的選項。Relay 不會自動啟用，只有使用者確認後才會使用。

每次重新進入聊天室時，都會重新優先嘗試 Direct P2P，不會因為之前曾使用 Relay 就一直使用 Relay。

## 隱私

- 聊天紀錄保存在目前瀏覽器裝置上。
- Direct P2P 模式下，聊天資料直接在雙方裝置之間傳輸。
- 使用 Relay 時，WebRTC 連線仍為加密傳輸。
- 清除瀏覽器網站資料或重設身分後，原本的本機聊天資料可能無法恢復。

## 使用提醒

部分公用 Wi‑Fi、公司、學校、飯店或特殊網路環境可能會限制 P2P 連線。如果無法直接連線，可以依畫面提示選擇加密 Relay。
